# 🎯 Визуализатор диаграмм Эйлера и операций над множествами

Интерактивное веб-приложение для наглядного построения диаграмм Эйлера/Венна и выполнения основных операций теории множеств. 

🌐 **Живой проект:** [https://p0m1d0r4ick.github.io/Euler_diagrams/](https://p0m1d0r4ick.github.io/Euler_diagrams/)

---

## 🚀 Основные возможности

* **Динамическая математическая модель:** Расположение множеств рассчитывается в реальном времени с помощью **силового алгоритма (Force-Directed Layout)**. Круги автоматически сближаются при наличии общих элементов, расходятся при их отсутствии и вкладываются друг в друга при подмножествах.
* **Операции над множествами:**
  * 🔻 Пересечение ($\cap$)
  * 🔺 Объединение ($\cup$)
  * ➖ Разность ($\setminus$)
  * 🔷 Симметрическая разность ($\triangle$)
* **Рендеринг формул:** Отображение математических выражений с помощью библиотеки **KaTeX**.
* **Интерактивный интерфейс:** Поддержка генерации случайных множеств, темной и светлой темы оформления, а также вывод полной информации о мощности множеств и расположении элементов.

---

## 🛠 Технологии

* **HTML5 Canvas** — отрисовка диаграмм и симуляция физики
* **Vanilla JavaScript** — логика операций и алгоритм размещения
* **CSS3** — адаптивный дизайн и темы
* **KaTeX** — математическая верстка
