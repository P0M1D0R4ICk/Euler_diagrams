# Визуализатор диаграмм Эйлера и операций над множествами

Интерактивный инструмент, который по заданным множествам строит **диаграмму Эйлера**: на ней присутствуют только те зоны пересечений, которые реально существуют в данных, а площади зон приблизительно пропорциональны числу элементов. Правильность каждой построенной диаграммы проверяется автоматически.

**Живой проект:** https://p0m1d0r4ick.github.io/Euler_diagrams/

## Что умеет

- **Множества и универсум.** Множество задаётся буквой и списком чисел. Универсум по умолчанию равен объединению всех множеств; можно задать его явно, тогда элементы вне множеств размещаются в области «вне всех множеств», а граница универсума показывается автоматически (или по переключателю).
- **Операции:** пересечение, объединение, разность, симметрическая разность. Результат подсвечивается на диаграмме, формула отображается через KaTeX.
- **Расстановка чисел по зонам.** Каждое число ставится в свою зону (только A, A и B, и т. д.) и расталкивается от соседей «пружинами».
- **Легенда, подписи, масштаб.** Подписи в одну букву с выносками, легенда с цветом и числом элементов, масштабирование колёсиком и перетаскиванием, светлая и тёмная тема.
- **Штриховка пересечений** цветами тех множеств, которым принадлежит зона, чтобы было видно, что именно пересекается.

## Как строится диаграмма

Идея в том, чтобы сначала описать диаграмму **абстрактно**, а потом найти для неё геометрию и проверить результат.

1. **Таблица зон.** У каждого элемента есть сигнатура: в каких множествах он лежит. Все элементы с одной сигнатурой образуют зону. Любая операция над множествами вычисляется по этой таблице, поэтому ответ всегда точный и не зависит от картинки.
2. **Производные множества.** Множество, которое целиком состоит из целых зон других множеств (например, `C = A ∩ B` или `E = A \ (B ∪ D)`), не получает собственной фигуры. Оно рисуется пунктиром по границам зон, из которых состоит. Совпадающие множества (`A = B`) делят один контур.
3. **Три способа построить геометрию** (применяются по порядку, пока проверка не пройдёт):
   - **«Звезда»:** общее ядро и у каждого множества собственная зона. Строится как «луковица с хвостом», хвосты сходятся к ядру через плавный переход.
   - **Эллипсы:** положение и форма эллипсов подбираются методом отжига, площади зон приближаются к пропорциональным. При добавлении нового множества поиск начинается с прежней раскладки, поэтому старые фигуры двигаются мало.
   - **Разбиение на зоны:** каждой зоне даётся своё «пятно», пятна подбираются силовой раскладкой, а множество собирается как объединение своих зон. Здесь границы соседних множеств могут совпадать на участке, и тогда они рисуются чередующимися штрихами цветов.
4. **Валидатор.** Проверяет, что все нужные зоны есть, лишних нет, каждая зона и каждое множество связны, а перемычки между частями множества не слишком узкие. Внизу холста показывается результат и максимальная ошибка площади. Если корректную диаграмму построить не удалось, программа так и говорит и называет проблемную зону или множество.

## Ограничения

- Надёжно проверялось на наборах до 3–4 множеств; отдельные наборы из пяти–шести множеств тоже строятся, но гарантии нет. Для более чем восьми независимых множеств используется прежняя раскладка без проверки.
- Расчёт сложных наборов может занимать около двух секунд.
- В режиме «звезда» площади зон не пропорциональны (ошибка порядка 30%).
- Для некоторых наборов диаграмму построить не удаётся. Это ожидаемо: не всякое описание множеств можно изобразить без разрывов и узких мест.
- Универсум задаётся только конечным списком чисел.
- Для формул KaTeX нужен интернет (библиотека загружается с CDN).
- Масштабирование двумя пальцами на сенсорных экранах пока не поддерживается.

## Примеры для проверки

| Набор | Что демонстрирует |
|---|---|
| A{1,2}, B{1,3}, C{1,4} | «звезда»: общее ядро без парных пересечений |
| A{1,2,3,4}, B{3,4,5}, C{6,7} | обычная диаграмма на эллипсах |
| A{1,2,3}, B{3,4,5}, C{3}, D{1,11}, E{2} | производные множества: `C = A ∩ B`, `E = A \ (B ∪ D)` |
| A{1,2,3}, B{3,4,5}, C{1,8,9}, D{2,11,12} | разбиение на зоны: A покрыто тремя непересекающимися множествами |
| A{1,2,3,4}, B{3,4,5}, C{5,6,7} | «цепочка» A–B–C с пустой собственной зоной B |
| A{1,2,3}, B{3,4,5}, C{5,6,7}, D{4}, E{4,8,9,0}, F{8,10,11} | шесть множеств, `D = B ∩ E`, B состоит только из трёх пересечений |

## Технологии

- HTML5 Canvas, ванильный JavaScript без сборки, один файл `index.html`

- GitHub Pages для публикации

## Об авторстве

Код написан с помощью ИИ-ассистента (Claude, Anthropic): автор формулировал требования и критерии корректности, проверял результат на собственных примерах, находил и описывал ошибочные случаи и выбирал направление развития.
